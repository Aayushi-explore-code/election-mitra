# 🗳️ Indian Election Mitra

**Empowering 900+ million voters through interactive civic education.**  
*Built for PromptWars: Vibe Coding Challenge 2026*

---

## 🌟 The Vision
"Indian Election Mitra" is an AI-assisted educational tool designed to simplify the complex journey of an Indian voter. From checking the electoral roll to understanding the 7-second VVPAT rule, this assistant makes the process **interactive, accessible, and easy-to-follow.**

## 🛠️ Key Features
*   **Interactive Voter Journey**: A step-by-step horizontal roadmap of the election cycle.
*   **Neo-Brutalist ID Vault**: A visual gallery of the 12 ECI-approved documents with a "Ready-to-Vote" check.
*   **EVM Simulator**: A high-fidelity mimic of the Indian Ballot Unit with VVPAT animation.
*   **Civic Assistant**: A contextual help system to solve common voting queries.

## 🛠️ Tech Stack & Google Integration
- **IDE**: Developed using **Google Antigravity** (Agentic Workflows).
- **Cloud Platform**: Deployed on **Google Cloud Run** (Serverless).
- **Infrastructure**: Managed via **Google Artifact Registry**.
- **Testing**: Automated unit tests using **Vitest/Testing Library**.

## 🚀 Tech Stack & "Vibe"
*   **Aesthetic**: Neo-Brutalist (High contrast, bold borders, Digital India Blue palette).
*   **Framework**: React 18 + Vite.
*   **Styling**: Tailwind CSS for rapid, efficient UI development.
*   **Animations**: Framer Motion for "springy," engaging interactions.
*   **Dev Workflow**: Built using **Google Antigravity** agentic workflows.
